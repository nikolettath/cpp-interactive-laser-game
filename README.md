# 2D Combat Simulation

A local multiplayer 2D game developed as a two-person university project to practice object-oriented programming in C++. This project was built and compiled in Visual Studio 2022 for Windows (x64), dynamically linking the Simple Game Graphics (SGG) library for rendering and input handling.

## Tech Stack
* **C++** 
* **SGG Library** (Graphics & Input handling)
* **Visual Studio 2022**

## Mechanics & Highlights
* **Custom Physics**: Built a simple gravity and jumping system from the ground up.
* **Collision Detection**: Box intersection logic for players, lasers, and static environment boundaries.
* **Game State Management**: Smooth transitions between the main menu, active gameplay, and the game-over screen.
